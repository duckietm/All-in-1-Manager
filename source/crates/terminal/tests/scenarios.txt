# Byte sequences fed into both the C# TerminalEmulator (tools/parity-terminal) and the Rust port
# (crates/terminal/tests/golden.rs). Each scenario writes tests/golden/<name>.txt.
#
#   scenario <name> <columns> <rows>
#   feed <bytes>             escapes: \e ESC, \r, \n, \t, \s space, \\ backslash, \xHH raw byte; other text as UTF-8
#   repeat <count> <bytes>   feeds <bytes> <count> times, with %d replaced by the 0-based iteration number
#   resize <columns> <rows>
#   select <line> <column> <line> <column>   writes Text((line, column), (line, column)) to the dump
#   dump                     writes the whole state (the end of a scenario dumps it too)
#   end
